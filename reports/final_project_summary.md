# Real-Time Object Detection using YOLOv5 - Final Project Summary

## Objective

Build a reproducible YOLOv5-based object detection project with dataset preparation, fine-tuned production weights, genuine labeled test evaluation, official COCOeval metrics, command-line inference, and a Flask visualization application for image, video, and webcam detection.

## Dataset Preparation

The project uses COCO 2017 object-detection data converted to YOLO format. The prepared full split contains 98,629 training images, 12,328 validation images, and 12,330 test images. The faster experiment used a deterministic 20,000-image COCO training subset and a 2,500-image validation subset during training.

For final labeled testing, the exact deterministic 2,500-image test subset was recreated from `data/splits/test_images.txt` with `random.Random(42).sample(full_test_paths, 2500)`. The generated manifest is `data/splits/test_subset_2500_seed42.txt`.

## Model

- Architecture: YOLOv5s, YOLOv5 v7.0
- Production checkpoint: `models/yolov5s_coco20k_best.pt`
- Classes: 80 COCO classes
- Parameters: 7,235,389
- Checkpoint SHA256: `8e75b741661acbd882cad802ab2d177cb636a0327af74dca944fbd3db5e10ee6`

## Training Configuration

Training artifacts show 6 configured epochs and 4 completed epochs in `results.csv`. The best epoch by validation `mAP@0.5:0.95` was epoch 0.

- Best validation precision: 0.70704

- Best validation mAP@0.5: 0.61301
- Best validation mAP@0.5:0.95: 0.38618

## Flask Application Verification

The Flask application supports image upload detection, video upload detection, webcam MJPEG detection, result metadata, confidence/IoU controls, optional class filtering, downloadable outputs, and model metadata APIs.

- Image detection: physically verified through Flask
- Video detection: physically verified through Flask
- Webcam detection: physically verified through Flask
- Observed physical webcam performance: 2.4 FPS, 324.1 ms latency, 1 object
- Browser video compatibility: repaired by generating an H.264/AVC MP4 from the existing annotated WhatsApp video

## Deployment Readiness

The project is ready for local Windows execution with Python 3.11 and the provided `.venv` setup instructions. The local environment uses CPU PyTorch; GPU training was intended for Colab or a CUDA-capable environment.

## Limitations

- CPU inference is slow for video and webcam workflows.
- The physical webcam performance values are manually observed, not generated by automated tests.
- Screenshot files are not fabricated; `reports/screenshots/README.md` documents the expected evidence filenames.
- Large datasets and generated outputs should be excluded from Git or handled with Git LFS where appropriate.

## Final Conclusion

The project is functionally complete for internship review: production model artifacts are verified, inference workflows are implemented, genuine labeled testing and official COCOeval are complete, Flask visualization is operational, and final audit artifacts document repository readiness and remaining size/packaging considerations.
